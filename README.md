# موقع قنفات الضجيج

معرض ومشغل كنب وقنفات — مجمع كتارا، الضجيج، الكويت. الطلب عبر واتساب 65061072.

## التقنية

- **Astro** موقع ثابت سريع، يُبنى ويُنشر تلقائيًا على **GitHub Pages** مع كل تعديل على `main`.
- **Sveltia CMS** لوحة تحكم عربية على `/admin/` تكتب مباشرة في هذا المستودع (بدون قاعدة بيانات أو سيرفر).
- **السلة** تعمل في متصفح الزائر وترسل الطلب جاهزًا إلى واتساب (المنتجات، الكميات، الأسعار، الروابط، المجموع).

## أين أعدّل؟

| ماذا | أين |
| --- | --- |
| المنتجات والصور والأسعار | اللوحة ← المنتجات |
| نصوص الأقسام والخدمات | اللوحة ← الأقسام / الخدمات |
| رقم المحل، ساعات العمل، الخريطة، إنستقرام | اللوحة ← بيانات المعرض |
| الاسم والهاتف والعنوان الأساسي | `src/data/business.ts` |
| عنوان الموقع (الدومين) | `astro.config.mjs` ← `SITE` |

## قواعد

- **القسم يظهر في الموقع فقط عندما يكون فيه منتج منشور** (لا صفحات فارغة لجوجل).
- **صفحة «كل المنتجات»** تُستبعد من جوجل (noindex) حتى يُضاف أول منتج.
- أسماء المنتجات رسمية حسب النوع، مثل «كنب زاوية مودرن رمادي»، بدون أسماء تجارية مخترعة.
- الأسعار بالدينار الكويتي، وتظهر بثلاث خانات عشرية (250.000 د.ك).

## الربط بالدومين dajeejsofa.com (لاحقًا)

1. أضف ملف `public/CNAME` فيه سطر واحد: `dajeejsofa.com`
2. غيّر `SITE` في `astro.config.mjs` و`site_url` في `public/admin/config.yml` إلى `https://dajeejsofa.com`
3. في Hostinger أضف سجلات DNS الخاصة بـ GitHub Pages.
4. في المستودع: Settings ← Pages ← Custom domain ← `dajeejsofa.com` ← Enforce HTTPS.

## التشغيل محليًا

```bash
npm install
npm run dev
```
